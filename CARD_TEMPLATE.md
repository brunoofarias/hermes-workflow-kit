# Modelo de card inicial

```text
Organização/projeto:
Tenant/domínio:
Repositório(s) ou workspace:
Link do sistema de origem:
Problema/objetivo:
Ambiente:
Critérios de aceite:
Evidências/links:
Restrições:
Executor: auto | <executor permitido pela organização>
```

Criar o card não inicia a execução. A pessoa responsável deve conferir o contexto e mover manualmente o card inicial para `ready`.
